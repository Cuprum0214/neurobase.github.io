## 十、入门导读建议（学习路径）

1. **零基础**：Bear《探索脑》(#3) → Ward (#8) 或 Anderson (#10)。
2. **建立体系**：Purves (#2) → Kandel (#1)（配《神经科学》#47）。
3. **BCI 方向**：+ Rao (#35) → Wolpaw (#34) → Nam 手册 (#38)。
4. **做方法/实验**：Luck (#27, ERP) → Cohen (#28, 时序) → Huettel (#29, fMRI)。
5. **做解码/算法**：Dayan & Abbott (#41) → Gerstner (#42) → Bishop (#45)。
