# PROJECT_SCOPE · 项目范围说明

> 本文件界定《神经与认知科学基础学习网页》项目的范围：做什么、不做什么、目标、边界、交付物与约束条件。
> **本文件以 `PLAN.md` 为准**；若与 `PLAN.md` 存在冲突，一律以 `PLAN.md` 为准。
> 任何超出本文档「范围内」条目的工作，默认视为范围外，需经变更确认。

---

## 一、项目概述

### 1.1 背景
需要一套**体系化、结构化、可离线使用**的《神经与认知科学基础》学习资料，面向大学本科入门学习者。为便于随时学习、交互理解与自测，本项目以**纯静态学习网页**的形态交付，而非仅交付文本内容，也不是需要后端支撑的在线系统。

### 1.2 一句话定义
> 交付一个**可直接离线打开、内容准确、交互丰富、便于长期维护**的「神经与认知科学基础」学习网站，覆盖四大模块共 15 章，配套测验、交互可视化、实践板块与运营维护体系，适合大学本科入门水平。

### 1.3 项目性质
- 类型：**纯静态 Web 学习站点项目**（前端静态站，无后端、无构建）
- 形态：HTML + CSS + JavaScript，双击 `index.html` 即可离线打开
- 语言：简体中文
- 范围：神经科学 + 认知科学基础知识，含交互式实践配套

## 二、项目目标

### 2.1 总目标
交付一个**内容准确、离线可用、交互丰富、可持续维护**的神经与认知科学基础学习网站，帮助大学本科入门学习者系统掌握四大模块核心知识并能够自测与实践。

### 2.2 分目标
1. **内容完整**：覆盖四大模块共 15 章，结构统一、深度适配本科入门。
2. **可自测**：每章配套测验（8-12 题，≥80% 判定通过）与全站术语闪卡。
3. **可视可交互**：5 类交互可视化 + 实践配套（虚拟解剖 / 实验模拟 / 伦理辩论）。
4. **易导航**：站点地图、面包屑、侧边栏目录、交叉链接，任意页面 3 次点击内可达。
5. **有引导**：首页首访引导 + 使用指南 + FAQ。
6. **可维护**：更新日志、编辑指南、版权页，支撑后续长期迭代。
7. **离线优先**：核心功能不自动加载外部资源，断网双击仍完整可用；联网时提供来源核实增强（见 §4.9）。

### 2.3 成功标准（验收维度）
- [ ] 15 章齐备，每章通过 Chapter DoD（见 PLAN.md §7.1）。
- [ ] 实践配套全部交付并通过 Labs DoD（见 PLAN.md §7.2）。
- [ ] 导航与运营维护通过 Ops & Nav DoD（见 PLAN.md §7.3）。
- [ ] 全站自动化自测 `tools/run_all.mjs` 全绿。
- [ ] 6 个阶段人工验收全部通过，达成 PLAN.md §8 退出条件。

## 四、范围内（In Scope）—— 本项目要做什么

### 4.1 内容生产（四大模块 15 章）
- 编写 **15 章**学习网页，覆盖：
  - **模块 A 神经元与电信号**：神经元结构与类型、静息电位与动作电位、突触传递与神经递质
  - **模块 B 脑结构与功能分区**：中枢神经解剖概览、大脑皮层分区与功能定位、神经影像与研究方法
  - **模块 C 感知与运动**：感觉系统总论与躯体感觉、视觉系统、听觉/前庭/化学感觉、运动系统与运动控制
  - **模块 D 高级认知**：学习与记忆、注意与执行功能、语言、情绪与动机、决策与意识
- 每章包含：学习目标、4-6 小节正文（约 1500-2500 字）、小结、关键术语、测验。
- 每个知识点按**七要素**呈现：定义 / 机制 / 关键结构 / 关键数据 / 图示 / 常见误区 / 关联；关键公式呈现但不推导；争议/前沿标注「了解」。（详见 `PLAN.md` §5.1）

### 4.2 交互可视化（5 类）
- 交互式脑区地图、动作电位动画、突触传递动画、神经通路示意图、概念关系图。
- 全部以 SVG/CSS 绘制，支持鼠标/触摸交互，附文字说明。

### 4.3 测验与学习工具
- 每章 8-12 题（单选/多选/判断），提交即判分并展开解析，≥80% 判定通过。
- 术语表 + 闪卡（翻面记忆、标记「已掌握」）、学习进度追踪（localStorage）。

### 4.4 实践配套（labs/）
- **虚拟解剖**：交互式脑/神经解剖浏览器（分层、点选、标签开关、剖面、自测模式）。
- **生理实验模拟 ×3**：膜电位与动作电位、突触传递、视觉感受野。
- **认知实验模拟 ×3**：Stroop、反应时、记忆广度。
- **伦理辩论**：≥6 议题库，含背景、正反方论点、伦理框架、讨论问题、个人立场记录。

### 4.5 导航与定位
- 站点地图页、面包屑、侧边栏全站目录、交叉链接（术语↔章节↔可视化↔实验）。

### 4.6 帮助引导
- 首页首访引导、使用指南、常见问题（FAQ ≥8 条）。

### 4.7 运营维护
- 更新日志（含版本号）、编辑指南（面向后续维护者）、版权与许可页（版权/引用规范/免责声明/第三方资源清单）。

### 4.8 技术规范与质量保障
- 纯静态、**离线优先 + 在线增强**、`file://` 兼容（经典 script 注入数据，禁 fetch/ES Module）。
- 建立自动化自测脚本集（`tools/*.mjs`），覆盖结构、链接、内容、题库、数据、离线、控制台、实践、站点地图、交叉链接、运营维护、引用来源与在线核实。

### 4.9 在线核实（Online Verification）
- 站点为「离线优先 + 在线增强（三级）」：① 断网仍 100% 可用 → ② 用户点击「核实来源」外链核对 → ③ `http(s)` 托管时「检查来源更新」自动核查版次。
- 关键来源登记于 `window.REFERENCES`（`references-data.js`），含版次/年份/标识符与 `verifyUrls`。
- 自动核查数据源：Crossref / OpenLibrary / Google Books（均支持 CORS）；结果缓存 `localStorage`（`ncs.refCheck`），失败静默降级。
- 不引入后端（维持 N1）；纯 `file://` 下自动核查不可用（自动降级），用户触发核实仍可用。
- 允许用户主动外链核实；仍禁止**自动加载**第三方脚本 / 字体 / CDN。详见 `PLAN.md` §3.5。

## 五、范围外（Out of Scope）—— 本项目不做什么

> 以下内容**明确不在**本项目范围内；如需，另立项目或走变更流程。
> **说明**：v1.0 中「不做 App/UI/多媒体/动画」等条目已被 v2.0 取代——本项目正是要交付网页界面、交互可视化与教学模拟。

| 编号 | 不做的事项 | 说明 |
| --- | --- | --- |
| N1 | **不自建 / 不自研后端** | 无自建服务器、无自研 API 与数据库运维。反馈箱的云端能力由第三方托管服务 **Supabase（BaaS）** 提供（数据库 / Auth / RLS / RPC 均为托管能力，无需自维护服务端）；未配置时降级为纯离线 |
| N2 | **不做原生 App / 小程序 / SSR** | 仅浏览器静态站，无客户端打包与原生版本 |
| N3 | **核心内容不依赖自动加载的外部资源** | 离线优先：不得有外链字体、远程图片、CDN 脚本等**自动加载**资源；**允许**用户主动点击的在线核实外链（见 §4.9） |
| N4 | **不生成 AI 写实插图** | 图示全部用内联/本地 SVG + CSS 绘制 |
| N5 | **不做科研级仿真精度** | 虚拟解剖与实验模拟为**教学演示级**，不追求科研精度、不做真实数据采集与上传 |
| N6 | **不提供临床诊断或医疗建议** | 疾病与相关内容仅作教学，不具医疗用途 |
| N7 | **不做患者 / 被试的实证数据采集** | 不含人体或动物实验、数据采集与伦理审批执行 |
| N8 | **不复制受版权保护的教材原文** | 仅以自撰表述与知识点组织呈现，引用需合规 |
| N9 | **不做多语言版本** | 当前仅简体中文 |
| N10 | **不做商业化内容设计** | 不含付费计划、营销文案、运营策略 |
| N11 | **不做 CMS / 在线编辑器 / 组卷系统** | 内容为静态文件，无后台编辑能力 |
| N12 | **不保证覆盖全部前沿最新文献** | 前沿内容以教材与代表性工作为主 |

## 七、边界与假设（Boundaries & Assumptions）

### 7.1 边界
- **内容边界**：仅限学科基础知识；不做垂直科研专题的深度综述。
- **深度边界**：以本科入门教学深度为准，知识点按七要素（定义/机制/结构/数据/图示/误区/关联）呈现；关键公式呈现但不推导；高阶部分点到研究入口，争议/前沿标注「了解」。
- **技术边界**：纯静态前端，不承担后端服务、账号与数据同步。
- **联网边界**：离线可完整学习；在线核实为增强功能，其可用性依赖网络与第三方站点，不作可用性保证。
- **精度边界**：模拟与解剖为教学演示级，不作为科研或临床依据。
- **服务边界**：不提供在线答疑、批改等运营服务。

### 7.2 假设
- 用户使用最新版主流浏览器（Chrome / Edge / Firefox）打开本地 HTML。
- 使用者具备基本中文阅读与自主操作能力。
- 内容可随教学需要裁剪与二次组织。
- 教师/领域专家可在交付后参与内容复核。

## 八、约束条件（Constraints）

### 8.1 内容约束
- 准确性优先：以主流教材与共识结论为准；存在争议的内容需标注。
- **准确性保障**：关键结论以可溯源字段记录来源（来源类型/来源/定位）；引用必须真实，禁止编造作者、书名、年份、页码、DOI；不得复制受版权保护原文（详见 `PLAN.md` §5.2）。
- 术语采用规范/通用译名并中英对照，全站唯一化。
- **离线引用呈现**：来源以纯文本呈现，不使用可点击外链；`check_offline` 仅扫描资源加载型外部依赖。
- **末尾引用标注（强制）**：凡学习内容涉及引用，必须在正文末尾设「参考来源」区，正文标注与末尾条目一一对应，并与 `window.REFERENCES` 登记一致；不涉及引用则显式标注（详见 `PLAN.md` §5.2.7）。
- 面向本科入门：避免过度专业化，保持教学可读性。
- 伦理议题须中立呈现正反方，不下价值判断。

### 8.2 技术约束
- **零构建、离线优先**；`file://` 下核心功能必须可正常运行；不在核心路径**自动加载**任何外部资源（CDN / 外链字体 / 远程图片）。
- 允许**用户主动触发**的在线核实外链；**自动核查在 `http(s)` 托管下正式启用**（Crossref / OpenLibrary / Google Books，均支持 CORS），`file://` / 无网络时静默降级（见 §4.9 / `PLAN.md` §3.5）。
- 提供 `docs/DEPLOY.md`：`file://` 与静态托管两种运行方式说明。
- `fetch` 仅允许用于**在线核查**（远程 API）；读取本地数据仍禁 `fetch`/`XHR`，禁用 ES Module；统一经典 script。
- 存储使用 `localStorage`（键名前缀 `ncs.`，含版本号）。
- 响应式支持 320px-1920px，无横向溢出。
- **UI 主题**：全站统一「蓝色系科幻风格」（深空蓝底 + 电光青强调 + 发光/网格元素 + 深浅双模式）；色板令牌与视觉规范见 `PLAN.md` §3.4。

### 8.3 质量标准约束
- 每章通过 Chapter DoD；实践配套通过 Labs DoD；导航与维护通过 Ops & Nav DoD。
- 自动化自测 `tools/run_all.mjs` 必须全绿（0 error、0 死链、0 外部依赖、0 数据不一致）。
- 站点地图与实际文件、页脚版本号与更新日志必须一致。

### 8.4 法务与伦理约束
- 不得复制受版权保护的教材原文；引用需注明来源。
- 医疗与伦理内容仅供学习，不构成医疗建议。
- 涉及人类/动物研究的方法学内容仅作教学说明，不替代伦理审查。

### 8.5 资源与过程约束
- 单机、离线可编辑的纯文本工作流。
- 版本以文件为准，重大修订需记录版本号并写入 PLAN.md 变更记录。
- 临时/过程文件与交付物分离（交付物位于 `outputs/`、`docs/`；过程文件放入 `_work/` 或 `tools/`）。

## 九、验收标准（Acceptance Criteria）

对齐 PLAN.md §7 与 §8：

1. **完整性**：15 章 + 实践配套 + 术语表/进度/站点地图/帮助/维护页均存在且可打开。
2. **一致性**：站点地图覆盖全部页面；交叉链接双向有效；版本号一致；数据与文件一致。
3. **规范性**：命名、结构、编码符合第六、八节约定；无外部依赖。
4. **可用性**：离线双击可打开；按导航可顺畅学习、自测并通过实践配套。
5. **合规性**：无版权原文复制；无医疗建议性表述；伦理议题中立。
6. **可自测**：`tools/run_all.mjs` 全量通过；6 阶段人工验收全部通过。

## 十、风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| `file://` 下 fetch/module 失效 | 数据加载失败 | 全程经典 script + 内联/全局数据，已写入技术约束 |
| `localStorage` 行为差异 | 进度/立场丢失 | 键名带版本；失败时降级为会话内存并提示 |
| 可视化/模拟代码量大 | 阶段延期 | 阶段 1 冻结组件范式与 SVG 规范，后续复用 |
| 虚拟解剖 SVG 复杂度高 | 质量参差 | 建立分层 SVG 组件库与统一规范 |
| 伦理议题敏感 | 引发争议 | 中立呈现正反方，不下结论，提供伦理框架 |
| 实践配套范围膨胀 | 无法退出 | 阶段 6 锁定量（1+3+3+1），增删记入变更记录 |
| 内容存在事实性错误 | 影响可信度 | 关键结论标注来源类型；人工逐章验收把关 |
| 范围蔓延（新增后端/App 等） | 工期与质量失控 | 严格以本文档「范围外」为准，走变更流程 |

## 十一、变更管理

- 范围变更（新增/删减章节、实践项、调整交付形态）需明确记录：变更内容、原因、影响、版本号，并同步写入 `PLAN.md` §10 变更记录。
- 本文件为范围基线；每次重大变更后更新 `version` 与 `last_updated`。
- **本文件以 `PLAN.md` 为准**；两者冲突时以 `PLAN.md` 为权威。

## 十二、术语表

| 术语 | 含义 |
| --- | --- |
| 学习网页 / 学习站点 | 本项目的纯静态 HTML 站点交付物 |
| Chapter DoD | 每章「完成定义」验收清单（见 PLAN.md §7.1） |
| Labs DoD | 实践配套「完成定义」验收清单（见 PLAN.md §7.2） |
| chapter / 章节 | 15 章学习内容页面 |
| labs / 实践配套 | 虚拟解剖、实验模拟、伦理辩论板块 |
| 交叉链接 | 术语↔章节↔可视化↔实验之间的双向链接 |
| `file://` 兼容 | 无需服务器、双击即可打开运行 |
| In Scope / Out of Scope | 范围内 / 范围外 |
| 交付物 | 项目最终产出、可直接使用的文件 |
